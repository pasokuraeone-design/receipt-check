# レシート写真の確認手順

写真はチャットで読みます。この画面は、その読み取り結果（JSON）を確認してから保存するためのものです。画像をこのアプリのサーバへは送りません。URLにレシートの中身を付けないでください。

記入例は `examples/receipt-photo-import.example.json` です。合成データなので、中身を埋めても保存できません。

## 手順

1. チャットでレシート写真を読み、ボットから受け取った JSON ファイルを手元に保存します。
2. レシート照合の画面で「読み取り結果のJSON」を選びます。選んだ時点では保存されません。
3. 「同じ写真ファイル」で、ボットに送ったのと同じファイルを選びます。ブラウザの中だけでハッシュを計算し、JSONの値と違えば保存できません。再圧縮された別画像は別物です。
4. 赤い未確認を、レシートを見ながら埋めます。読めない数字は空のままにしてください。空のままでは保存できません。
5. 拠点（山手 / 新神野）、分類、支払方法は、レシートに書いていないことが多い項目です。自分で選ぶまで未確認のままです。アプリもボットも、これを推測で確定しません。
6. 金額が一致し、サーバが購入日と再送防止に対応していると確認できるまで、保存ボタンは押せません。対応が確認できないときは、日付を落とす従来の保存には切り替えません。
7. 保存に成功したと画面が言ったときだけ、入力が消えます。応答が確認できないときは内容が残ります。同じ内容でもう一度保存できます。

## 税と値引

- 外税: 品目の合計 − 値引 + 消費税 = レシートの合計。消費税は今までどおり、拠点ごとの行に1回だけ分かれます。品目の金額には足しません。
- 内税: 品目の合計 − 値引 = レシートの合計。画面の消費税欄は 0 のままです。内消費税は参考表示で、合計には足しません。
- 値引は1回だけ、独立した行です。各品目へ割り戻しません。値引があるときは、その拠点を選びます。

購入日はレシートに印字された日付です。この画面を開いた日時ではありません。

## カード払い

カードのレシートは、すでに自動取込された行の内訳として保存します。一覧から自分で行を選びます。日付や金額が近くても、自動では選ばれません。それは同じレシートの証明ではありません。

金額が違う行では保存できません。その行を0円にしたり、「重複なので無視」にしたり、もう1件のカード支出として足したりは、この取り込みからはやりません。自動取込の行が無いときは、この画面では保存できません。

## 再送

同じ写真をもう一度保存しても、サーバが写真IDを見て二重追加を止めます。これはサーバを更新したあと、画面に対応の確認が出ているときだけです。このブラウザに「すでに開いた」と出ても、それは画面の中の注意であり、サーバの保証ではありません。日付と金額が同じ別の写真は、別のレシートです。

# 合成データだけで試す Apps Script

これは本番のスクリプトでも、本番のスプレッドシートでもありません。新しい空のスプレッドシートに、新しい Apps Script として入れます。デモ用の HTML は模擬台帳であり、ここでの成功にはなりません。

## 入れるファイル

`Code.gs` を、新しいプロジェクトの `コード.gs` にそのまま貼ります。中身は `gas/photoReceiptImport.gs` と `Harness.gs` を結合したものです。本番の `コード.gs` の上には貼りません。

`appsscript.json` は、Apps Script のプロジェクト設定で「appsscript.json マニフェスト ファイルをエディタで表示する」をオンにしてから置き換えます。

## 必要な権限

使う Google アカウントは、新しいスプレッドシートと Apps Script を作れるアカウントです。本番のシートを開いているアカウントのまま作業しないでください。

初回実行の同意画面で求める範囲は、このプロジェクトが組み込まれたスプレッドシートだけです。マニフェストのスコープは次の1つです。

`https://www.googleapis.com/auth/spreadsheets.currentonly`

Gmail、ドライブ全体、外部への通信は要求しません。同意画面にそれらが出たら、許可せずに止めてください。

ウェブアプリとして公開する場合の設定は次です。

- 実行ユーザー: 自分
- アクセスできるユーザー: 自分のみ
- 「全員」にはしません
- 本番のデプロイ ID は使いません。新しいデプロイです

エディタで `runSyntheticSelfTest` を実行するだけなら、ウェブアプリのデプロイは不要です。

## 手順

1. Google スプレッドシートを新規作成する。名前は「レシート合成テスト」など、本番と紛らわしくないものにする。既存の買い物シートはコピーしない。
2. 拡張機能 → Apps Script を開く。できたプロジェクトは空のコンテナバインドである。
3. 既定の `コード.gs` を `Code.gs` の内容で置き換える。`appsscript.json` も置き換える。
4. 関数 `setupSyntheticSheet` を選んで実行する。権限を承認する。
5. 戻り値が「合成シートを用意しました。本番の取引はコピーしていません。」であること。シート `食料品_品目明細` の A列が `gmail-demo-a`、`gmail-demo-b`、`synthetic-manual` だけであること。
6. 関数 `runSyntheticSelfTest` を実行する。実行ログの戻り値が「合成セルフテスト 16 件すべて成功。本番のシートには書いていません。」であること。
7. シートを見て、次を確認する。

## 確認リスト

- 現金サンプルの B列は文字列 `2026/04/01 12:34` である。今日の日時でも、Date 型の取り込み時刻でもない。
- 品目の金額は 400 と 600 のままである。1080 が各品目に入っていない。消費税の行は 32 と 48 で、合計 80 である。J列と K列は空である。
- 同じ payload の再実行は行を増やさない。
- 写真IDの最後の1行を消して再実行すると、その1行だけ戻り、日付は `2026/04/01 12:34` のままである。
- `gmail-demo-a` を、別の行番号のまま更新しようとする処理は失敗し、金額は 1080 のままである。
- 正しい行番号かつ ID `gmail-demo-a` の内訳のあと、その行だけ拠点が `済`、分類が `内訳入力済み`、金額が 0 になる。`gmail-demo-b` は 500 のままである。新しい行の合計は 1080 で、カードの全額をもう1件足していない。
- 内訳の再実行は行を増やさない。
- 支払方法がカードの `photoReceiptImport` はエラーになり、行を足さない。
- 別の写真IDで、同じ日付・同じ合計の現金を入れると、別の行が増える。
- A列に `gmail-demo-`、`photo-`、`synthetic-` 以外の ID がある状態で `setupSyntheticSheet` を実行すると、何も消さずに止まる。

ウェブアプリまで見る場合は、自分のみの新しいデプロイを作る。ブラウザでその URL を開くと JSON に `synthetic: true` と `capabilities.photoReceiptImport: 1` と、カード行の `id` が入っている。この URL を本番の `index.html` には書かない。

## まだ本番ではない

このセルフテストが成功しても、本番のウェブアプリは変わっていません。公開中の `index.html` も、この合成プロジェクトを向いていません。認証のない公開 URL と、古い処理が行番号を信じること、は残っています。
